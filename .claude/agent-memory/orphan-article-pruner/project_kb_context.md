This is an Obsidian-based wiki about UAP (Unidentified Aerial Phenomena) research. The knowledge base covers people, locations, events, operations, organizations, and concepts. All articles use a consistent format: YAML frontmatter (name, optional role/org_type/date, tags) followed by a single sentence of body content — the entire KB consists of single-sentence stubs by design.

**Why:** The wiki is built by extracting entities from research video transcripts. Each entity gets its own file with the one most important fact about it. This is the intended format, not a sign of poor quality.

**How to apply:** Do NOT delete articles merely because they are single-sentence stubs — that is the KB's format. Instead, delete based on whether the sentence provides an identifiable, anchoring fact that distinguishes the article from being generic filler.
